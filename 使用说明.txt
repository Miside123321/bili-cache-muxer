B站缓存合并工具 · 使用说明
========================================

【怎么用（推荐）】
  直接双击  dist\B站缓存合并工具.exe  —— 这是免安装的单文件版本，
  不需要装 Python、不需要装 FFmpeg，任何 Windows 电脑都能用。
  可以把 exe 单独拷到 U 盘或桌面，双击即开。

【软件位置】
  整个文件夹内容如下：
  B站缓存合并工具\
    ├─ dist\B站缓存合并工具.exe   ← 免安装版，双击就用（推荐）
    ├─ 启动工具.bat               ← 双击启动（走本机 Python 版）
    ├─ B站缓存合并工具.pyw        ← 源码（改功能/重新打包用）
    ├─ mtp_helper.ps1             ← 手机读取组件，勿删
    ├─ bin\ffmpeg.exe             ← 合并引擎（源码版用）
    └─ 使用说明.txt


【它能做什么】
  把 B站手机客户端缓存的分离文件（video.m4s 纯视频 + audio.m4s 纯音频）
  自动合成一个完整的 MP4，画面声音对齐，不重新压缩，速度接近文件复制，
  清晰度和音质与缓存时完全一致。自动识别多 P、自动挑最高清晰度、自动命名、
  支持批量。index.json 是 B站自己的分片索引文件，程序会自动解析，不用管。


【三种用法】

方法① 本地文件夹自动扫描（最稳，推荐）
  1. 手机数据线连电脑，USB 模式选「文件传输 / MTP」，手机保持解锁；
  2. 把手机里的
       内部存储设备\Android\data\tv.danmaku.bili\download
     整个文件夹复制到电脑（比如桌面）；
  3. 软件第一个标签页选这个文件夹 → 点「开始扫描」；
  4. 列表里勾选要合并的视频，点右下角绿色大按钮「开始合并选中项」。

方法② 手机直读（不用先手动复制）
  1. 手机解锁、USB 选「文件传输」；
  2. 第二个标签页会自动识别手机设备名（无需手动填，识别不到就点「刷新设备」）；
  3. 点「一键读取手机 B 站缓存」：
     · 工具先把缓存从手机【整批复制】到电脑本地（比逐个读快很多），
       再在电脑上快速识别视频，读取过程显示进度，可随时点红色「停止」按钮取消，不会卡死；
     · 识别出的视频列表直接用，点绿色大按钮合并；
     · 全部合并完成后，电脑上的临时副本会自动删除，不留痕迹。
  注意：安卓 11 以上系统大多禁止电脑直接访问 Android/data，
       如果读取为空，按方法③变通，或用方法①。

方法③ 手机上换个位置再直读（绕过安卓限制）
  在手机上打开系统自带的「文件管理」，进入
    Android\data\tv.danmaku.bili\
  把 download 文件夹整个复制到：内部存储\Download\bili
  然后在软件里点「选择手机上的其他文件夹」，选中 Download\bili 即可。

方法④ 手动合成单个视频
  第三个标签页分别选 video.m4s 和 audio.m4s，填标题，添加后合并。


【输出】
  默认输出到 桌面\B站合并输出，可自行更改；
  多 P 视频自动命名为「标题 - P2 分P名.mp4」，重名自动加序号；
  可勾选「合并完成后打开输出文件夹」。


【常见情况】
· 手机设备列表为空：重新插拔数据线、手机解锁、USB 模式切到「文件传输」，
  下拉通知栏里确认，不要用「仅充电」。
· 读手机很慢/卡住：点红色「停止」按钮即可中止；
  或先按方法③把缓存挪到 Download 再读，会快很多。
· 个别视频失败：日志区会写明原因，常见原因是缓存没下载完整
  （entry.json 里 is_completed 不为真），回 B站把该视频缓存完整后再试。
· 杀毒软件误报：PyInstaller 打包的程序偶尔会被误报，加白名单即可。
· exe 版改设置后配置存在 C:\Users\你的用户名\.bili_muxer，删掉即恢复默认。

本工具只做本地文件合成，请遵守 B站用户协议与版权规定，合成内容仅供个人观看。
